- `PaintDryTimer.cpp`
- `Makefile`

#Description
This assignment has two parts. The first being a `TimeCode` class for dealing with hours, minutes and seconds. The second part consists of two subparts, a program that reads NASA's launch data (`NasaLaunchAnalysis`) and a `PaintDryTimer` that counts how much time it takes paint batches to dry using the TimeCode class.

#Compile 
Compiles by running TimeCodeTests.cpp, NasaLaunchAnalysis and PaintDryTimer.cpp and can also do that by typing make try in terminal
